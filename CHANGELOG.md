# Changelog

Notable changes to the twinthos-ai-sec-audit skill. There are no tagged releases yet, so entries are grouped by merge date, newest first. Numbers are GitHub issues (`issue #N`) or pull requests (`#N`).

## Unreleased

- AI security checklist: 24 core checks across eight domains (identity/access, agent configuration, secrets/data, deployment, governance, integration, monitoring, supply chain) plus four optional deeper checks (prompt-injection boundaries, repository governance, secret handling design, agent recovery).
- Bundled CLI reader with allow-listed field selection for safe metadata reads.
- Markdown-to-HTML renderer with offline assets and structural QA.
- Optional JSON report model with validation and append/rebuild.
- Full reference set: capabilities, checklist, collection plan, MCP check map, MCP boundary, browser evidence, evidence assessment, report model, report template, report design.

## 2026-10-31

Initial community preview of the Twinthos AI Security Audit skill, adapted from the Vercel Security Audit pattern with AI/agent-specific checks and Twinthos branding.
